# Contributing

CYBERVOYRAX Workspace values readable source code, realistic application behavior, reproducible lab state, and deliberate security design.

Before contributing:

1. Keep features believable for an internal business workspace.
2. Do not add a vulnerability merely to create a challenge.
3. Avoid comments or naming that reveals intended weaknesses.
4. Keep intentional-vulnerability details out of learner-facing documentation.
5. Preserve project attribution and applicable license/notice requirements.
